Entry for the make.fun bounty "Fix Human Sleep: Funniest Patch Note": a single line of patch notes announcing that human sleep has been fixed.

> Fixed: counting sheep now works. Sheep are capped at 12 per night; additional sheep will be queued.

## How to run

```sh
node main.ts
```

This writes the patch note to `/output/entry.txt`.

## Why this line

Counting sheep is the oldest sleep remedy there is, and the patch note treats it like a real feature with a real limit: capped at 12 per night, extras queued. That is exactly how a changelog would phrase a resource cap, which makes the absurdity land on one read with no explanation. It is a fresh angle — nobody else in the field used sheep — and the fix is specific and surprising rather than a flat claim that sleep now works. Short, terse, and confident, like a real release note.
